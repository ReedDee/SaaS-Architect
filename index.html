  • Task breakdown
  • Dependencies
  • Build order
  • Acceptance criteria per task

Master engineering specification covering all architectural decisions
  • Complete specifications
  • Architecture & data models
  • Interfaces & contracts
  • Requirements
  • Legal obligations
prompt.md
Self-contained executor prompt — cold session needs no prior context
  • Full context
  • Constraints
  • Acceptance criteria
  • Deliverables
  • Build sequence
tasks & phases
architecture & contracts

🚀
Executor
Cold session — no prior context needed. Reads plan.md + spec.md + prompt.md and builds task by task.
⌨Coding
Implements tasks from plan.md task by task — files, components, wired integrations
🐛Debugging
Systematic-debugging skill — root-cause before fix, no random patches
✅Verification
verification-before-completion — evidence before any done claim
💾Checkpoints
Writes .executor-checkpoint.md after each task — crash-safe resume
🔒Plan-locked
No scope creep — deviations surfaced to founder, not silently absorbed
📋Spec-aware
Reads spec.md constraints before each task — architecture decisions enforced
